# Voranix Launcher

Launcher de Minecraft de la comunidad Voranix.

## Descargar

Descarga el instalador **`VoranixLauncher-Setup-<versión>.exe`** desde la
[última versión](https://github.com/SobrinoDev/VoranixLaucher/releases/latest)
(sección *Assets*).

- Solo Windows (64 bits).
- Si Windows muestra "Windows protegió su PC", pulsa **Más información → Ejecutar de todas formas**.
- El launcher se actualiza solo: cuando haya una versión nueva aparecerá
  **"Reiniciar para actualizar"** en la barra superior.
